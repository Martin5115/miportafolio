## Tech

Built with **pure HTML and CSS**, with no frameworks, no build step and no dependencies. It is a single `index.html` file, which keeps it fast and easy to maintain.

- Responsive layout (CSS Grid and Flexbox)
- Dark theme with CSS variables
- Accessible: semantic HTML, visible focus states, `prefers-reduced-motion` support
- Fonts: Oswald and Work Sans (Google Fonts)

## Run it locally

No installation needed. Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/Martin5115/miportafolio.git
cd miportafolio
```

## Deploy

Hosted on **GitHub Pages**: *Settings → Pages → Deploy from a branch → `main` / root*. Every push to `main` updates the site.
